{# Projects inside one experience entry — one per client engagement at a services company, or any project a role was made of. Each project prints one compact line from the parts it has, in this order: client (or the project's name when there's no client) · domain · role, then its dates the way the template prints a role's, then its points. Name and technologies otherwise stay in the profile: the line is kept short on purpose. A project with none of those parts still prints its dates and points under the role. {% endif %} {% if p.bullets %} {% for b in p.bullets %}{% endfor %}

{% endif %}
